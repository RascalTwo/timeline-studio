Durations are hours of work, spent only inside the windows below. Work stops at the end of a window and resumes at the next one — a task keeps its duration and takes longer on the calendar, which is what the shaded gaps are. A day off is a day with no windows, and a date can have its own.
What the row label says, then what this plan calls each channel and the values behind it. Removing a value reassigns its tasks rather than orphaning them.
A channel is a rendering, not a meaning — so a meaning can move. Send “dev / QA / prod” from the border to the fill and the tasks come with it; what you choose below is how each one should be drawn once it gets there. Nothing is merged, and it is a big change — Save first if you might want it back.
How far the chain lights up. Hover is a glance — you are sweeping the pointer to see what each bar touches, so it stays shallow; a click is deliberate, so it reaches further. Anything past the limit is still drawn, just left grey: you asked not to be told should not look like there is nothing there.
Four relationships, four styles. Solid is one hop, dashed is the rest of the chain — so a colour reads as a direction and the dash as distance. Stored on the plan, so a plan can carry its own convention.
A task's reference is half a link. This is the other half, and it lives in this browser, for this plan only — never on the document, so it is not in the plan, not in the archive, and not in the link you hand someone to show them the chart. That is deliberate: a reference names a row in a system it does not identify.

Nothing here belongs to a plan. Import creates a new plan for each one in the file — it never writes over a plan that already exists, and the ids in the file are only suggestions. Each new plan gets its own link, and that link is the only way back to it.

Review

A lane is a serial queue and ties break by position, so the order rows sit in is the order that team works in — and it is the one scheduling input that leaves no arrow on the chart. Each move below is measured against the order you have now, so applying one changes the rest: they are recomputed after every apply.

Timeline Studio

A delivery plan you can argue with in the room. Lanes are queues that can only do so much at once, tasks wait on each other, and the date at the top is computed, never typed — so when someone says "could that start later?", you drag it and everyone watches the answer move.

The link is the key. A plan has no login and no owner — anyone holding its link can read and edit it, and the link is the only way back to it. There is no list of your plans and no way to recover one from a lost link. Keep it somewhere you keep things, and share it exactly as widely as you mean to.
